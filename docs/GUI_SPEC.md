# GUI Specification

> Карточный roguelike со словами в эстетике казино/покера. Игрок выкладывает WordCards из руки на WordSlots, формируя набор ассоциативных карт, то есть карты могут принадлежать одной категории, затем жмёт Play. Очки считаются  и накапливаются в Score до целевого значения уровня.

---

## 1. Общая концепция

- **Жанр**: Word-based deckbuilder roguelike (вдохновение: Balatro + Word association)
- **Визуальный стиль**: казино/покер — зелёное сукно + бежевые игральные карты
- **Базовое разрешение**: 1920×1080, адаптивный layout
- **Ориентация**: Landscape (горизонтальная)

### Палитра

| Назначение | Цвет | Применение |
|---|---|---|
| Фон сукно | `#1B5928` (тёмно-зелёный) | Background, паттерн мастей |
| Карты фон | `#FFF8EE` (тёплый off-white) | Внутренность WordCard |
| Карты рамка | `#F0DDB8` (бежевый) | Внешняя рамка WordCard |
| Текст основной | `#1A1A1A` | Слово на карте |
| UI белый | `#FFFFFF` | Плашки счётчиков |
| UI фиолетовый | `#5D3D5C` | Обводки UI |

### Цвета бонусов на WordCard (по тиру)

Цвет плашки `BonusBadge` зависит от значения очков — это даёт игроку быстрое визуальное считывание силы карты.

| Тир | Диапазон | Цвет плашки | Цвет текста |
|---|---|---|---|
| `none` | 0 | плашка скрыта | — |
| `low` | +1 ... +5 | `#7FB069` (зелёный) | белый |
| `mid` | +6 ... +15 | `#3D8FCC` (синий) | белый |
| `high` | +16 ... +30 | `#B967A5` (пурпурный) | белый |
| `legendary` | +31 и выше | `#E8A02D` (золотой) | белый |

*Точные диапазоны можно подкрутить под баланс — главное закрепить, что цвет зависит от силы.*

## 4. Компоненты — Counters

### 4.1 `ScoreProgressBar`
- **Позиция**: top-right
- **Содержимое**: лейбл "Score" / текущее значение `63` / прогресс-бар / целевое `/240`
- **Поведение**: заливка анимируется при добавлении очков

### 4.2 `HandsCounter`
- **Позиция**: правая сторона, под Score
- **Содержимое**: лейбл "Hands" + цифра — сколько раз можно сыграть Play в текущем раунде

### 4.3 `SwapCounter`
- **Позиция**: левая сторона, верх
- **Содержимое**: лейбл "Swap" + цифра — сколько Swap-операций осталось

### 4.4 `SwapSelectionCounter`
- **Позиция**: левая сторона, под `SwapCounter`
- **Содержимое**: `0/3` — сколько WordCards в руке помечено для обмена

---

## 5. Компоненты — Buttons

### 5.1 `PlayButton`
- **Позиция**: правая сторона, по центру вертикали (на уровне WordSlots)
- **Форма**: большой гексагон/круг с иконкой ▶
- **Действие**: сабмит текущей комбинации, расчёт очков
- **Состояния**: `default` / `disabled` (если слоты пусты) / `pressed` / `hover`

### 5.2 `ReturnAllButton`
- **Позиция**: правая сторона, под `PlayButton`
- **Форма**: компактная кнопка с иконкой ⤺
- **Действие**: возвращает все WordCards с WordSlots обратно в Hand
- **Состояния**: `default` / `disabled` (если WordSlots пуст)

---

## 6. WordSlots (центральная зона)

### 6.1 Контейнер `WordSlots`
- **Позиция**: центр экрана, по горизонтали
- **Структура**: 8 ячеек в ряд (`WordSlot[]`)
- **Gap между ячейками**: 8-12px

### 6.2 Отдельный `WordSlot`
- **Соотношение сторон**: **3:4** (как у `card-base.png`)
- **Состояния**:
  - `empty` — полупрозрачный контур карты на сукне
  - `filled` — содержит `WordCard`
  - `highlighted` — подсветка при drag-over

### 6.3 Поведение
- Перетаскивание `WordCard` из `Hand` на свободный `WordSlot`
- Reorder между слотами
- Клик на размещённую карту — возврат в Hand

---

## 7. WordCard (главный объект игры)

### 7.1 Базовый ассет
- Использовать `assets/card-base.png` как фон карты
- Размер в игре: пропорция 3:4

### 7.2 Анатомия карты

```
┌───────────────────┐
│              ╔══╗ │  ← BonusBadge (правый верх)
│              ║+20║    скрыта если bonus == 0
│              ╚══╝ │    цвет зависит от тира
│                   │
│    ┌─────────┐    │
│    │  WORD   │    │  ← WordText (центр)
│    └─────────┘    │
│                   │
└───────────────────┘
```

### 7.3 Элементы карты

| Элемент | Описание | Условия отображения |
|---|---|---|
| `WordCard` | Корневой контейнер карты (использует `card-base.png`) | всегда |
| `WordCard.WordText` | Само слово на карте (центр) | всегда |
| `WordCard.BonusBadge` | Плашка `+N` в правом верхнем углу | только если `bonus > 0` |

### 7.4 BonusBadge — детали

- **Позиция**: правый верхний угол карты, с небольшим отступом от края
- **Форма**: скруглённый прямоугольник или плашка-тикет
- **Содержимое**: `+N` (где N — значение бонусных очков)
- **Цвет фона**: по тиру (см. таблицу в разделе 1)
- **Видимость**: 
  - `bonus === 0` → плашка **полностью скрыта** (не показывать "+0")
  - `bonus > 0` → показать с цветом тира

### 7.5 Состояния `WordCard`
- `inHand`, `onBoard`, `selected`, `dragging`, `playing`

---

## 8. Hand (рука игрока)

### 8.1 Контейнер `Hand`
- **Позиция**: нижняя часть экрана, во всю ширину
- **Лейбл**: "Hand" в левом верхнем углу панели
- **Фон**: белый прямоугольник с фиолетовой обводкой
- **Содержимое**: `WordCard[]` (рекомендую 5-7)

### 8.2 Поведение
- Карты в ряд с равными gap
- Перетаскивание на WordSlot → карта исчезает из Hand
- Клик в режиме Swap → пометка карты, апдейт `SwapSelectionCounter`

## 9. Background

- **Ассет**: `assets/back.jpg`
- **Применение**: на всю сцену, под всеми UI элементами
- **Стратегия рендера**: cover (растянуть на viewport) или tile (тайлинг)

## 10. State Machine — игровой flow

```
[ROUND_START]
     │
     ▼
[PLAYER_TURN] ─────────┐
     │                 │
     │ карты на        │ жмёт Swap
     │ WordSlots       │
     ▼                 ▼
[CARDS_ON_BOARD]   [SWAP_SELECTION]
     │                 │
     │ Play            │ подтверждение
     ▼                 ▼
[SCORING] ─────► [HAND_REFILLED] ───► [PLAYER_TURN]
     │
     │ Score >= Target?
     ▼
[ROUND_WIN] / [ROUND_LOSE если Hands == 0]
```
