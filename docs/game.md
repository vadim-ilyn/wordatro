# Игровые понятия:
`DECK`: колода карт которая состоит из карточек со словами, все карточки записаны в json уровня
`CARD`: карта, содержит слово, также каждая карточка имеет поле с количеством бонусных очков, 
которые начисляются при подсчете очков руки.
`HAND`: карты которые игрок перенес на игровую доску, которые будут учавствовать в подсчете очков.
`SLOT`: ячейка для 1ой карты на игровой доске 
 
# Правила и параметры игры:

## Начальная настройка параметров уровня:
1. Из конфига уровня берутся все категории со словами под каждое слово в `wordsIds` массиве создается карточка с 
текстом, где текст это слово. То есть колода `DECK` это все слова из всех категорий 'categories[*].wordsIds',
то есть количество карта в `DECK` это сумма всех слов всех категорий.
2. После того как `DECK` создана карты необходимо перемешать.
3. Каждой карте необходимо добавить текстовое поле с количеством бонусных очков, по умолчанию у всех карт это 0 очков,
если у карты 0 очков текстовое поле на карте не отображается, если больше 0 тогда отображается. 
У каждого количества очков свой цвет, 10 например зеленый, 20 синий, и т.д. у каждого уникального значения свой цвет.
4. В конфиге уровня есть поле 'bonus_points' c массивом чисел, необходимо для случайных карт в колоде добавить бонусные
очки, если размер массива 'bonus_points' 10 тогда 10 случайным картам в колоде необходимо начислить эти очки.
Карты с бонусами должны быть **разбросаны по колоде в случайном порядке**, а не идти подряд первыми. Иначе все
бонусные карты придут игроку в первую же руку и нарушится баланс.
Рекомендуемая реализация: после первого shuffle присвоить бонусы первым N картам и затем **повторно перемешать**
колоду — это распределит карты с бонусами равномерно случайно по всей колоде.
5. Также необходимо получить из конфига уровня количество очков которое необходимо чтобы пройти уровень, 
поле `target_points`, задать значение для отображения в интерфейсе игрового поля.
6. Замена карт, игрок может перетащить от 1 ой до X карт из руки в специальный слот `exchanger`, после чего нажать
кнопку 'replace' и получить из колоды в руку такое же  количество карт сколько он перенес в слов `exchanger`.  
Установка количества попыток замены карты и количества карт которое можно заменить за один раз.
Из `game_config.json` необходимо получить значение `replace_attempts_count` это количество раз которое на протяжении 
всего уровня игрок может заменить карты в руке, при этом игрок может заменить максимум за 1 раз такое количество карт
которое задано в значении `max_cards_replace_count`, то есть игрок может за уровень {N} количеств раз заменить {X} количество карт. 
7. На старте уровня игрок получает заданное в `start_hand_size` количество рандомных карт из колоды.
8. Счетчик карт в колоде уменьшается каждый раз когда из колоды `DECK` берутся карты.
9. На игровое поле/доску игрок может перетащить от 1ой до {N} заданного количества карт в поле
`play_cards_slots_amount`, файл game_config.json.

##  Описание последовательности этапов игры, 
на протяжении игры игрок собирает N рук, колиcтво `HAND` задается в конфиге уровня:

1. На старте игры из колоды игрок получает в руку N рандомных карт.
Стартовое количество карт задается в game_config.json поле `start_hand_size`.
2. Игрок может перенести N карт на доску, может заменить выбранные карты в руке согласно правилам игры
3. После того как игрок перенес выбранные карты на доску он может сыграть нажав кнопку "Play"
4. На доске проверяются карты которые перенес игрок, определяется сколько карт принадлежит какой категории,
какой категории количество карт больше те карты остаются на доске, остальные карты помечаются перечеркнутым крестиком,
потом через секунду удаляются с доски.
Если несколько категорий имеют одинаковый максимум. Например игрок выбрал 5 карт:
2 карты категории A
2 карты категории B
1 карта категории C
Максимум — 2 карты. Очки будут 20 у обоих категорий A и B. 
Если несколько категорий имеют одинаковое максимальное количество карт, выбирается та категория, которая дает больше очков с учетом суммы очков бонусов для карт каждой категории. Если и с учетом бонусных очков у двух категорий общее количество
очков тогда выбирается любая одна категория.
5. После того как на доске остались карты одной категории, которых оказалось больше. 
Из оставшихся карт которые принадлежат одной категории подсчитываются очки за сыгранную руку, согласно
правилам подсчета очков
6. Отображается количество очков которые получил игрок за карты на доске, 
подсчитываются вначале очки за количество карт, затем начисляются бонусные очки которые могут быть
на отдельных картах. Суммируется количество очков за количество собранных карт и по отдельности бонусные очки каждой карты.
Покащывается общее количество очков.
7. Очки за сыгранную руку добавляются в общий подсчет очков игрока
8. Карты которые остались у игрока в руке, то есть он их не перенес остаются у игрока в руке,
из колоды игрок получает необходимое количество карт чтобы в сумме у игрока в руке стало количество карт
которое задано в game_config.json поле `start_hand_size` в game_config.json файле.
9. Такии образом игрок может сыграть N `HAND` то есть набрать N раз игровую руку 
- Розыгрыш 1-ой руки это с 1ого по 8 шаг включительно (первый раз игрок получает 8 карт сразу так как рука пустая)
- Розыгрыш 2-ой руки это с 2ого по 8 шаг включительно (у игрока могут остаться карты после отыгранной предыдущей руки)
- Розыгрыш N-ой руки это также с 2ого по 8 шаг
10. За каждую сыгранную `HAND` игрок получает очки, коорые суммирутся в общем счетчике очков
11. Если за N `HAND` рук игрок не набрал необходимое количество очков для прохождения уровня он проиграл
и может переиграть уровень снова, появляется кнопка Restart, если выиграл переходит на следующий уровень. 
Количество очков необходимое для прохождения уровня задается в поле `target_points` конфига уровня.
12. **Досрочное завершение уровня**: как только `score >= target_points`, уровень считается пройденным
сразу же, даже если у игрока остались неотыгранные руки (`handsLeft > 0`). Игра останавливается,
показывается окно Level Complete. Доигрывать оставшиеся руки нельзя.
Проверка выполняется в этом порядке: сначала `LEVEL_COMPLETE` (если набрал target),
затем `GAME_OVER` (если `handsLeft === 0` и не набрал), иначе `PLAYER_TURN`.

## Подсчет очков:
1. В зависимости от того сколько карт одной категории игрок собрал на игровой доске игрок получает
заданное количество очков, количество очков за каждый набор задается в конфиге игры `game_config`, 
в котором количество карт в руке соответствует ячейке массива "points_progression":[10,20,30,50,100,250,500,1000],
за 1 карту 10 очков, за 4 карты 50 очков и т.д.
2. Бонусные очки, суммируются все бонусные очки каждой карты на игровой доске.
3. В итоге суммируются количество очков за количество карт + бонусные очки каждой карты.
4. Игроку **обязательно показывается математика начисления** через всплывающий блок (`ScorePopup`).
Без этой визуализации игрок не понимает откуда взялось такое количество очков. Popup должен содержать:
   - количество выигравших карт и базовые очки за это количество (например `4 cards = +50`)
   - бонусные очки с разбивкой по картам если возможно (например `Bonuses +20 +30 = +50`)
   - итоговая сумма (`Total = +100`)
   - изменение общего счёта (`Score: 40 → 140`)
   Popup появляется после удаления проигравших карт, висит ~1.5–2 секунды (или до клика игрока),
   затем исчезает и общий `Score` визуально обновляется.
   Имя категории-победителя в popup **не показывать** — категории не отображаются на UI в принципе.
 
# Элементы игрового поля и интерфейса:
1. доска для размещения карт, на доску можно положить N карт, зависит от значения поля `play_cards_slots_amoun`
в game_config.json. Каждая карта ложится в отдельную ячейку.
2. количество `hands` на уровень, значение в поле `hands_count` в файле `game_config.json` 
3. счетчик очков сверху по центру
4. кнопка вернуть все карты в руку
5. колода справа в нижнем углу со счетчиков карт в колоде,
под колодой отображается текст например: "10/45" оставшееся количество карт в колоде и общее количество карт колоды.
**Над колодой** отображается короткая плашка с составом колоды формата `N × M cards`, где N — число
категорий в текущем уровне, M — количество карт в каждой категории. Например для level 1: `5 × 8 cards`
(5 категорий по 8 карт = 40 карт всего). Текст всегда на английском, максимально короткий.
Имена категорий **не раскрываются** — игрок видит только числовую структуру, чтобы планировать сбор.
Если у категорий разное количество карт, fallback: `T cards / N cats` (T = общее число карт).
6. кнопка Play, когда на игровой доске в слотах нет ни одной карты она серая и не активная,
когда в любом слоте появляется карта кнопка становится активной
7. После того как уровень выигран появляется поп ап окно с кнопкой следующий уровень.
8. Если игров проиграл появляется поп ап окно с кнопкой restart.
9. Также на игровом экране отображается слот `exchanger` над слотом значок RESET
под слотом пишется "0/3", 0 это текущее количество карт в слоте а 3 это максимальное количество карт которое можно
перетащить в слот, параметр в поле `max_cards_replace_count` в конфиг файле game_config.json. 


# Управление:
- Можно перетаскивать карты из руки в слоты игровой доски
- По клику на перенесенную карту на игровую доску она возвращается в руку, пока игрок не нажал "Play"
игрок может заменять карты в руке, возвращать карты с доски в руку
- Игрок может перетаскивать карты из руки в слот `exchanger` также по клику на карту в слоте `exchanger`
она возвразается в руку игрока.
- Игрок может нажать кнопку Play, после чего происходит запуск определения карт на доске и подсчет очков согласно правилам
